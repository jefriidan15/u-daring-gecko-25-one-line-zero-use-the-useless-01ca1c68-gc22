## The line

> I can hear what my houseplants are thinking, and every single one of them is disappointed in my watering schedule.

One sentence, 114 characters. A hilariously useless superpower:
telepathy that only works on houseplants — and all it ever
reveals is disappointment about the watering schedule.

## Why this line works

- **Funny** — the premise is absurd (mind-reading, but only for
  ferns) and the payoff is a domestic guilt trip delivered by
  something that cannot even talk back.
- **Fresh** — the uselessness is specific: the power works, the
  information is real, and it is worth absolutely nothing.
- **Neatly worded** — one sentence, setup and payoff in the same
  breath, with the turn landing on the last two words.

## How to run

Requires Python 3.13 (standard library only, no dependencies).

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` — UTF-8, one sentence,
114 characters, no trailing newline. Set `OUTPUT_DIR` to write
elsewhere:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
```
